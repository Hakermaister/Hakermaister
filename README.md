Kanał o administracji Linuxem w praktyce. Konfiguracja serwerów, zarządzanie usługami (systemd), sieci, firewall, SSH, kontenery i wirtualizacja, automatyzacja w Bashu i Pythonie, a do tego narzędzia, dzięki którym praca admina jest szybsza i prostsza.
